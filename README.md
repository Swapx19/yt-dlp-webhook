# yt-dlp Webhook

A FastAPI webhook for Make.com to download YouTube Shorts using yt-dlp.

## Deployment

### 1. Using Render.com
1. Create a GitHub repo (public) and push these files.
2. On Render, choose **New → Web Service**, connect your repo.
